01 / INTRO

时尚正在为“繁荣”松绑

大家情绪

我们有些厌倦了收束

长期 Clean / Less 的审美收束后，人们开始重新渴望颜色、装饰和表达感。所谓繁荣回潮，本质是对“生活还有兴致”的向往。

行业信号

从克制走向感官浓度

秀场重新出现复杂层次、华丽材质与夸张配饰；Maximalism、Ornament、Print Mixing 再次成为行业语言。

02 / WHAT IS PROSPERITY

什么是繁荣主义？

表象：不以拥有更多贵东西为前提。而是通过更「丰富的色彩」、交织更「有想象力的层次」，或是带有打扮欲溢出的「配饰叠搭」、或是上身繁荣气场的「高存在感材质」，让有限的衣橱重新产生丰盛感。

内里：通过丰富多彩的装饰打扮，让自己看起来状态更好。大环境的不确定性、秋冬的凋零都不能掩盖大家对待生活和自己的积极态度——我们倡导通过打扮，让自己看起来更加有生命力。

❌ 不是以前的极繁主义

不是依赖珠宝华服、蓬蓬裙支架与盖茨比式大牌堆叠。

❌ 不是以前的极简主义

不是只判断留白、版型与质感的低浓度“少而精”。

✅ 是新的繁荣主义

外放的高浓度时尚：有限的衣橱但不无聊，甚至带一点叛逆。

03 / OUTFIT INSPIRATION

繁荣主义穿搭灵感

择一即繁荣。主体→感官→局部，穿搭表达更简易、更日常。

3.1 主体繁荣｜层次多 × 颜色多，最直白最一针见血的繁荣

暗戳戳繁荣
繁荣主义初尝试｜外套下是我的穿搭巧思，局部露出层次与颜色。
层叠系繁荣
繁荣主义尖子生｜运用极致色彩和层次，搭出高浓度繁荣感。
印花派繁荣
印花够多，就够繁荣｜让不同花纹与颜色碰撞，穿得丰富也穿得有趣。

3.2 感官繁荣｜用高存在感材质，打造繁荣的观感和触感

亮片
内搭 / 裙装｜光线落下时，自带闪耀与庆祝感。
闪钻
外套 / 内搭 / 裤装｜让日常单品拥有更直接的华贵气场。
钉珠
内搭 / 半身裙｜细密装饰制造近看更繁荣的质感。
流苏
裙摆 / 包 / 衣摆 / 创意单品｜走动时摆起来，动态比静态更有感官浓度。
丝绒
外套 / 裤装 / 裙装｜通过光泽与触感，穿出浓郁的丰盛感。
重工刺绣
拿破仑外套｜一件完成造型主张，上身即有繁荣气场。

3.3 局部繁荣｜配饰变主角，叠戴繁荣感

手饰叠戴
量感大 / 数量多 / 材质多｜从手腕开始增加装饰浓度。
项链叠戴
量感大、长度长｜或以更多数量、不同材质形成层次。
胸针叠戴
局部叠戴 / 大量感胸花｜把装饰集中在一个位置，张力更清晰。
腰间叠戴
大量感、吸睛花纹、不同材质｜用腰间装饰改变整套穿搭的视觉重心。
